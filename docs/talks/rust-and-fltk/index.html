Requirements

  • Runs on Microsoft Windows
  • Single file executable
  • Windowed GUI
  • Cut and Paste

Proposed Solution

  • Nix: simple* build environment.
  • Rust: easy LLM coding. (better error messages make for fewer bugs when “vibe” coding.)
  • FLTK: small cross platform GUI library. Statically linkable.

Nix has a reputation for making cross platform building easy. Maybe it was not necessary here.

What about an icon?

Where does an icon live?

  • MS Windows embeds icons into the executable. Great!
  • Linux: a desktop file points to program and icon files.
  • MacOS: the icon is part of the package. (?)

Have Rust embed the icon

crate winresource

A build.rs file runs at compile time.

fn main() {
    // Embed the application icon into the Windows executable.
    if std::env::var("CARGO_CFG_TARGET_OS").as_deref() == Ok("windows") {
        winresource::WindowsResource::new()
            .set_icon("assets/basket.ico")
            .compile()
            .expect("failed to embed Windows icon");
    }
}

The build.rs file is used to handle external dependencies like C libraries, etc. OK, why not use the MinGW utility?
